# Photos on the butler's tray

Each service on the welcome page shows real photos in circles above the tray. Sebastian finds them
automatically (from Pexels if PEXELS_API_KEY is set, otherwise public-domain photos from Openverse).

To use your own photo instead, save it in this folder with the name shown below (a square JPG,
at least 300 x 300 pixels). Your photo always takes priority. Only use photos you have the right to use.
